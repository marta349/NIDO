Sobre la seguridad de tus datos

Actualmente NIDO funciona como un prototipo local. Los datos de esta versión se almacenan en el navegador del dispositivo.

Cuando conectemos el sistema de cuentas, NIDO utilizará un servidor y una base de datos para gestionar de forma segura la información.

🗑️
Eliminación de datos

La eliminación completa de los datos de la cuenta estará disponible cuando NIDO tenga conectado el sistema real de cuentas.
